# Order & Delivery Policy

## Order statuses
- PLACED: order received, not yet shipped.
- SHIPPED: order in transit.
- DELIVERED: order received by customer. Refunds are only possible after delivery.
- CANCELLED: order cancelled before shipment.
- RETURNED: order returned and refund completed.

## Delivery dates
The delivery date recorded on the order is the start of the 14-day return window. Customers should check their order page for the exact delivery date.

## Order information privacy
Customers can only view their own orders. Support staff can view order context for tickets they handle. Order details are never shared between customers.
